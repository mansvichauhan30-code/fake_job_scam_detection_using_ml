# Resume Description

## Project Title
**JobShield AI — Fake Job Scam Detection System**

## Short Description (1-liner)
Built a full-stack ML-powered web application that detects fraudulent job
postings using NLP-based classification and rule-based red flag analysis,
achieving real-time scam probability scoring for job seekers.

## Resume Bullet Points (Choose 3-5)

- Designed and developed a full-stack **Fake Job Scam Detection System**
  using **Flask, MySQL, and Scikit-learn**, enabling users to assess job
  postings for fraud in real time.

- Built and trained a **TF-IDF + Logistic Regression** machine learning
  model on labeled job posting data to classify postings as fake or
  genuine, achieving high accuracy on test data.

- Implemented a **rule-based red flag detection engine** identifying 7
  scam indicators (unrealistic salary, missing company details, money
  requests, suspicious email domains, grammar issues, urgency tactics,
  unrealistic claims) to complement ML predictions.

- Designed a **weighted scoring algorithm** combining ML model confidence
  (70%) with rule-based red flag analysis (30%) to produce a 0-100% scam
  probability score with auto-generated, plain-English explanations.

- Developed a **responsive Bootstrap 5 UI** with user authentication
  (session-based, password hashing), a personal dashboard with statistics,
  searchable/filterable report history, and an admin panel for user
  management.

- Designed a normalized **MySQL database schema** (3NF) with `users`,
  `job_analyses`, and `red_flag_master` tables, including foreign key
  constraints and indexing for performance.

- Implemented secure backend practices including parameterized SQL
  queries, role-based access control (user/admin), and PBKDF2 password
  hashing via Werkzeug.

## LinkedIn / Portfolio Summary (longer version)

> JobShield AI is a full-stack web application I built to address the
> growing problem of fake job postings online. The system combines a
> trained Machine Learning model (TF-IDF vectorization + Logistic
> Regression) with a rule-based red flag detection engine to analyze job
> postings across 7 fraud indicators — including unrealistic salaries,
> missing company information, requests for upfront payments, suspicious
> recruiter email domains, and language patterns common in scams. Users
> receive a 0-100% scam probability score along with an AI-generated,
> plain-English explanation of the verdict. The application features
> secure user authentication, a personal dashboard tracking analysis
> history and statistics, searchable report history, and an admin panel
> for system oversight — all built on a Flask backend with a normalized
> MySQL database and a responsive Bootstrap 5 frontend.
